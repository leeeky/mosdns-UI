## 智能解析，根据路由和选择本地出局解析和远端解析

mosdns WebUI 的核心价值是智能解析。它不是简单地把所有 DNS 请求都转发到同一个上游，而是可以根据域名类型、规则资产和用户自定义规则，把不同域名交给更合适的 DNS 上游处理。以实现智能准确的100%分流

使用智能解析后，可以实现：

- 国内常用域名走本地 DNS，上网响应更快。
- 海外或特殊域名走远端 DNS，减少错误解析。
- 指定域名走指定上游，方便处理特殊业务、办公系统或个人规则。
- 内网域名固定解析到指定 IP，局域网服务访问更稳定。
- 规则资产自动同步，长期保持智能分流能力。
- 浏览器页面直接配置，不需要手动编辑 mosdns 配置文件。

适合的场景：

- 企业有海外线路，需要用到dns分流场景
- 可兼容企业原来的windows dnsserver方案
- 办公室环境，希望 DNS 更稳定。
- 想区分国内域名和海外域名的解析路径。
- 有一些域名需要手动指定 DNS 上游。

## 智能解析怎么工作

智能 DNS 模式下，系统会把 DNS 请求分成不同类型处理：

- 命中静态解析的域名，直接返回用户配置的固定 IP。
- 命中自定义规则的域名，使用该规则里指定的上游 DNS。
- 命中规则资产的域名，按智能分流逻辑选择对应上游。
- 未命中特殊规则的域名，使用默认的上游策略继续解析。

用户主要需要理解四个配置项：

- 监听配置：决定客户端把 DNS 请求发到哪里。
- 本地上游池：适合填写国内、运营商或局域网 DNS。
- 远端上游池：适合填写海外公共 DNS 或加密 DNS。
- 自定义规则：用于让指定域名固定走指定上游。

## 推荐配置流程

第一次使用建议按下面顺序配置：

1. 进入 Web 页面。
2. 选择“智能 DNS”模式。
3. 设置监听地址和监听端口。
4. 配置本地上游池。
5. 配置远端上游池。
6. 按需要添加自定义规则。
7. 按需要添加静态解析。
8. 点击“保存配置”。
9. 启用 mosdns 服务。
10. 使用“解析测试”检查结果是否正常。

## 一分钟推荐配置

如果只是想快速启用智能解析，可以先按下面配置。

监听地址：

```text
0.0.0.0
```

监听端口：

```text
53
```

解析模式：

```text
智能 DNS
```

本地上游池：

```text
119.29.29.29
223.5.5.5
```

远端上游池：

```text
tls://8.8.8.8
tls://1.1.1.1
```

配置完成后点击：

```text
保存配置
```

然后点击页面上的启用按钮，让 mosdns 开始工作。

## 监听配置

监听配置决定客户端应该把 DNS 请求发送到哪里。

### 监听地址

常用配置：

```text
0.0.0.0
```

表示监听服务器所有网卡地址，局域网内其他设备也可以使用这台服务器作为 DNS。

如果只想监听某个固定局域网 IP，可以填写：

```text
192.168.1.1
```

如果服务器有多个网卡，可以添加多个监听地址。

### 监听端口

正式使用一般填写：

```text
53
```

如果只是临时测试，可以填写：

```text
5353
```

使用 `53` 端口时，请确认系统里没有其他 DNS 服务占用该端口。

## 智能 DNS 配置

智能 DNS 是推荐使用的核心模式。它可以根据域名和规则，把请求分配到更合适的 DNS 上游。

### 本地上游池

本地上游池用于处理更适合走国内或本地网络的域名。

常见填写：

```text
119.29.29.29
223.5.5.5
```

也可以填写运营商 DNS、路由器 DNS 或内网 DNS。

适合放在本地上游池里的 DNS：

- 国内公共 DNS。
- 运营商 DNS。
- 公司或家庭内网 DNS。
- 对国内域名解析速度更快的 DNS。

### 远端上游池

远端上游池用于处理更适合走远端公共 DNS 的域名。

常见填写：

```text
8.8.8.8
1.1.1.1
```

也可以填写 mosdns 支持的加密 DNS 格式，例如：

```text
tls://8.8.8.8
https://dns.google/dns-query
```

适合放在远端上游池里的 DNS：

- 海外公共 DNS。
- DoH DNS。
- DoT DNS。
- 对特殊域名解析更准确的 DNS。

具体上游格式是否可用，以当前 mosdns 版本支持为准。

## 自定义规则

自定义规则用于手动指定某些域名走固定上游。

适合这些情况：

- 某个域名必须走指定 DNS。
- 某个业务系统解析结果不稳定。
- 某些域名希望绕过默认智能分流。
- 想单独给一组域名配置专用 DNS。

每条自定义规则包含：

- 规则名称。
- 域名列表。
- 上游 DNS。

### 域名列表怎么填

每行填写一个域名。

示例：

```text
example.com
test.example.com
service.company.com
```

### 上游 DNS 怎么填

每条规则最多填写两个上游 DNS。

示例：

```text
8.8.8.8
1.1.1.1
```

也可以填写国内 DNS：

```text
119.29.29.29
223.5.5.5
```

添加、修改或删除自定义规则后，需要点击“保存配置”才会生效。

## 静态解析

静态解析用于把某个域名固定解析到指定 IPv4 地址。

它的优先级适合用于内网服务，例如：

- NAS。
- 内网管理后台。
- Home Assistant。
- 公司内部系统。
- 测试环境服务。

示例：

域名：

```text
nas.home
```

IPv4 地址：

```text
192.168.1.10
```

一个域名可以配置多个 IPv4 地址：

```text
192.168.1.10
192.168.1.11
```

静态解析修改后，需要点击“保存配置”才会生效。

## 规则资产同步

规则资产是智能解析的重要基础。它帮助系统判断哪些域名应该走本地上游，哪些域名应该走远端上游。

页面支持：

- 手动同步规则资产。
- 开启定时同步。
- 设置同步时间。
- 查看上次同步时间。

### 手动同步

点击“手动同步”后，系统会立即尝试更新规则资产。

同步成功后，系统会自动重新加载 mosdns，并清理旧的 DNS 缓存。这样新下载的域名规则会被 mosdns 重新读取，后续新的 DNS 查询会按最新规则进行智能解析。

页面显示“规则资产同步完成，mosdns 已重新加载并清理缓存”时，表示新资产已经完成应用。

如果服务器当前不能联网，同步可能失败。离线安装包已经内置默认规则资产，不联网也可以先使用。

### 定时同步

开启定时同步后，系统会按 cron 表达式自动更新规则资产。

推荐每天凌晨自动同步：

```text
0 4 * * *
```

也可以设置每周同步一次：

```text
0 4 * * 0
```

定时同步适合长期运行的设备，可以减少后期维护。

## 代理 DNS 模式

代理 DNS 是更简单的转发模式，适合不需要智能分流，只希望统一把 DNS 请求转发到指定上游的用户。

这个模式下主要配置：

- 默认上游池。
- 自定义规则。
- 静态解析。

默认上游池示例：

```text
119.29.29.29
223.5.5.5
```

或：

```text
8.8.8.8
1.1.1.1
```

如果你的主要需求是智能解析，建议优先使用“智能 DNS”模式。

## 保存与生效

页面上的配置修改不会立刻改动 mosdns，必须点击：

```text
保存配置
```

以下操作都需要保存后才生效：

- 修改监听地址。
- 修改监听端口。
- 切换智能 DNS 或代理 DNS。
- 添加、修改、删除上游 DNS。
- 添加、修改、删除自定义规则。
- 添加、修改、删除静态解析。

这些操作会立即执行：

- 启用或停用 mosdns。
- 手动同步规则资产。
- 开启或关闭定时同步。
- 清除 DNS 缓存。
- 执行解析测试。

清除 DNS 缓存会弹出确认框，因为它会立即清空当前缓存。

## DNS 缓存

DNS 缓存可以提升重复查询速度。

缓存页面可以看到：

- 域名。
- 记录类型。
- 解析值。
- TTL。

如果修改了规则或上游后想立刻看到新结果，可以清除缓存再测试。

## 解析测试

解析测试用于确认智能解析是否正常工作。

可以测试：

- 国内域名是否能正常返回结果。
- 海外域名是否能正常返回结果。
- 静态解析是否命中。
- 自定义规则是否按预期返回。

常用测试域名：

```text
baidu.com
github.com
nas.home
```

测试完成后，页面会显示：

- 是否解析成功。
- 返回状态。
- 查询耗时。
- 返回的 IP 或记录内容。
- 失败原因。

## 启用和停用 mosdns

配置保存完成后，可以在页面上启用 mosdns。

启用后，mosdns 开始提供 DNS 服务。

停用后，mosdns 停止提供 DNS 服务。

如果启用失败，优先检查：

- `53` 端口是否被占用。
- 监听地址是否属于当前服务器。
- 上游 DNS 是否填写正确。
- 配置是否已经点击“保存配置”。

## 登录保护

如果管理员配置了登录保护，访问 Web 页面时需要输入用户名和密码。

常见配置项：

```env
WEBUI_USERNAME=admin
WEBUI_PASSWORD=你的密码
```

修改登录配置后，需要重启 WebUI 服务。

如果使用离线安装包，目标机器不需要提前安装 Node.js、npm 或 mosdns。

离线包已经包含：

- Node.js 运行环境。
- mosdns 程序。
- 默认规则资产。
- systemd 服务文件。

安装后访问：

```text

```

适合大多数用户。

监听地址：

```text
0.0.0.0
```

监听端口：

```text
53
```

模式：

```text
智能 DNS
```

适合 NAS、内网服务或测试服务。

静态解析域名：

```text
nas.home
```

```text
192.168.1.10
```

## 使用注意事项

- 推荐优先使用“智能 DNS”模式，这是本工具的主要能力。
- 修改配置后一定要点击“保存配置”。
- 删除规则、删除上游、删除静态解析不会立即生效，需要保存配置。
- 清除缓存、同步规则、启停服务是立即执行操作。
- 如果解析结果不符合预期，可以先清除缓存，再用“解析测试”检查。
- 如果客户端无法使用 DNS，请检查客户端 DNS 是否指向了服务器 IP。
- 如果 mosdns 启用失败，请检查端口占用和监听地址。
